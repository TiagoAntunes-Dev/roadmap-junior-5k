# 🎨 CSS Fundamentals

> *Pasta de estudo com base e documentação prática para o meu roadmap de CSS.*

Este repositório não é apenas um guia de sintaxe, mas um diário de bordo focado no **"porquê"** das propriedades. O objetivo é dominar como o navegador renderiza os elementos na tela, desde as engrenagens do Box Model até a fluidez do Design Responsivo, construindo uma base sólida, escalável e sem "gambiarras" visuais.

---

## 📚 Estrutura do Roadmap

Cada capítulo é uma pasta isolada, contendo um arquivo `index.html` e um `style.css` extensamente comentados, prontos para abrir, analisar e estudar.

| Lab | Capítulo / Pasta | Assunto e Conceitos-Chave |
|:---:|:---|:---|
| **01** | 🎨 **Chapter 1 - Basic CSS Syntax** | Sintaxe básica, as 3 formas de aplicar CSS (Inline, Interno, Externo). |
| **02** | 🎯 **Chapter 2 - Selectors** | Seletores de elemento, classe, ID, atributo, combinadores, pseudo-classes e pseudo-elementos. |
| **03** | 📦 **Chapter 3 - The Box Model** | Content, padding, border, margin, box-sizing e o comportamento de margin collapse. |
| **04** | ⚔️ **Chapter 4 - Handling Conflicts in CSS** | O motor do CSS: Cascata, especificidade, herança e o uso clínico do `!important`. |
| **05** | 📏 **Chapter 5 - Values and Units** | Unidades absolutas e relativas, sistemas de cores (HEX / RGB / HSL) e variáveis CSS nativas. |
| **06** | 📐 **Chapter 6 - Sizing** | Width / height, limites dimensionais (Min / Max), box-sizing e fit-content. |
| **07** | 🖼️ **Chapter 7 - Backgrounds and Borders** | Propriedades de background, gradientes, border, border-radius e box-shadow. |
| **08** | 🔗 **Chapter 8 - Styling Lists and Links** | List-style, estruturação de menus de navegação e estados de link (LVHA). |
| **09** | 🔤 **Chapter 9 - Web Fonts** | Font-family, importação via Google Fonts, `@font-face` e propriedades de texto. |
| **10** | 📱 **Chapter 10 - Responsive Design** | Manipulação de Viewport, Media Queries e a filosofia Mobile-First. |

---

## 🚀 Como Usar e Explorar

Para extrair o máximo destes laboratórios, siga este fluxo de análise:

1. **Abra a pasta** do capítulo que você deseja estudar.
2. **Execute o código:** Abra o `index.html` no navegador — ou clique com o botão direito e escolha *Open with Live Server* (extensão recomendada para o VS Code).
3. **Inspecione a arquitetura:** Leia os comentários detalhados dentro do `style.css`.

> 💡 **Dica de Engenharia:** Os comentários internos focam no **"porquê"** de cada propriedade, não apenas no "o quê". A ideia central deste repositório é fixar os conceitos lógicos e a mecânica do CSS, evitando que você precise apenas decorar sintaxe pura.
