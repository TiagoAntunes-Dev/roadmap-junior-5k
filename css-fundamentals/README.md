# css-fundamentals

Pasta de estudo com base para o meu roadmap de CSS.

## Estrutura

| Pasta | Assunto |
|---|---|
| Chapter 1 - Basic CSS Syntax | Sintaxe básica, as 3 formas de aplicar CSS (inline, interno, externo) |
| Chapter 2 - Selectors | Seletores de elemento, classe, id, atributo, combinadores, pseudo-classes e pseudo-elementos |
| Chapter 3 - The Box Model | content, padding, border, margin, box-sizing, margin collapse |
| Chapter 4 - Handling Conflicts in CSS | Cascata, especificidade, herança, !important |
| Chapter 5 - Values and Units | Unidades absolutas e relativas, cores (hex/rgb/hsl), variáveis CSS |
| Chapter 6 - Sizing | width/height, min/max, box-sizing, fit-content |
| Chapter 7 - Backgrounds and Borders | background, gradientes, border, border-radius, box-shadow |
| Chapter 8 - Styling Lists and Links | list-style, menus de navegação, estados de link (LVHA) |
| Chapter 9 - Web Fonts | font-family, Google Fonts, @font-face, propriedades de texto |
| Chapter 10 - Responsive Design | viewport, media queries, mobile-first |

## Como usar

Abra o `index.html` de cada pasta no navegador (ou use a extensão Live Server no VS Code) e leia os comentários no `style.css` — eles explicam o "porquê" de cada propriedade, não só o "o quê".
