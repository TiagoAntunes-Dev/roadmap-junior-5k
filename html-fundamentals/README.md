## 📌 Sobre o Repositório

Este repositório contém os exercícios práticos que desenvolvi acompanhando o tutorial gratuito de HTML para iniciantes do canal **Dave Gray**. 

O projeto consiste na estrutura de um site simples, cobrindo os conceitos fundamentais da linguagem de marcação. Decidi fazer o upload deste código para manter meu **roadmap de estudos público e organizado**, documentando cada etapa da minha evolução no desenvolvimento de software.

## 🧠 Conceitos Praticados neste Tutorial

Embora inicial, o laboratório cobriu a base necessária para a construção de páginas web:

* **Sintaxe Base:** Tags, atributos e a estrutura global de um documento HTML5.
* **Elementos de Texto:** Cabeçalhos (`<h1>` a `<h6>`), parágrafos (`<p>`) e formatação básica.
* **Listas e Links:** Organização de dados com listas ordenadas/não-ordenadas e navegação entre páginas.
* **Mídia:** Incorporação de imagens de forma local e remota.
