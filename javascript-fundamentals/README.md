# 📘 JavaScript Fundamentals

Cada seção do vídeo virou uma pasta própria, com um arquivo `.js`
comentado explicando o **porquê** de cada conceito — não só o "como" —
para reforçar o aprendizado ao reler o código depois.

## 🗂️ Como usar este repositório

1. Entre na pasta da seção que quer estudar.
2. Leia os comentários antes de rodar (eles explicam o raciocínio).
3. Rode o arquivo com Node para ver a saída no terminal:

```bash
node 05-tipos-de-dados/tipos-de-dados.js
```

4. Modifique valores, quebre o código de propósito, veja o que muda.
   É a melhor forma de fixar o conteúdo.


## 🧠 Método de estudo usado

1. Assistir o trecho do vídeo correspondente à seção.
2. Anotar os pontos-chave.
3. Reassistir codando junto, comparando com o arquivo desta pasta.
4. Passar as anotações principais para o caderno físico.

## ▶️ Pré-requisitos para rodar os exemplos

- [Node.js](https://nodejs.org) instalado (versão LTS recomendada).
- Nenhuma dependência externa é necessária — todos os exemplos usam
  apenas recursos nativos do JavaScript/Node.
