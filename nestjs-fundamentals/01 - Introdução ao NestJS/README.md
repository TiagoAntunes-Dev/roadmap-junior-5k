## 📖 O que é o NestJS?

O **NestJS** é um framework para construção de aplicações backend eficientes, confiáveis e altamente escaláveis. Construído com suporte nativo e profundo ao **TypeScript**, ele combina elementos de:

- **OOP** (Programação Orientada a Objetos)
- **FP** (Programação Funcional)
- **FRP** (Programação Reativa Funcional)

> 💡 **Nota de Arquitetura:** O NestJS foi criado para resolver o "problema de arquitetura" no ecossistema Node.js. Se você já está familiarizado com conceitos como Módulos, Injeção de Dependência, Decorators e a separação de responsabilidades entre Controllers e Services, a curva de aprendizado será extremamente fluida.

---

## ⚙️ Requisitos do Sistema

Antes de iniciar, certifique-se de que o seu ambiente de desenvolvimento possui:

- **Node.js**: Versão `>= 16` (Totalmente compatível e testado com as versões mais recentes, incluindo a `v26.x`).
- **Gerenciador de Pacotes**: `npm` (a versão 11+ funciona perfeitamente), `yarn` ou `pnpm`.
- **Editor de Código**: VS Code, IntelliJ IDEA ou similares.
- **Git**: Para controle de versão seguro do projeto.

## 🛠️ Passo a Passo: Instalação e Criação

O NestJS possui uma CLI (Interface de Linha de Comando) poderosa que automatiza a criação do projeto, a configuração do TypeScript e a geração de arquivos futuros (como rotas e serviços).

### 1. Instalar a CLI Globalmente
No seu terminal, execute o seguinte comando para disponibilizar a ferramenta `nest` em toda a máquina:

```bash
npm install -g @nestjs/cli
nest new project-name

```
### 2.Após a instalação, entre na pasta criada:

```bash
cd nome-do-projeto
```

## 📝 Resumo

O NestJS fornece uma estrutura organizada para desenvolver aplicações backend com Node.js e TypeScript.

Sua arquitetura baseada em **Modules**, **Controllers**, **Providers** e **Dependency Injection** facilita:

* 📦 **Organização do projeto**
* 🧩 **Separação de responsabilidades**
* 🔄 **Reutilização de código**
* 🧪 **Testabilidade**
* 📈 **Escalabilidade**
* 🛠️ **Manutenção da aplicação**
